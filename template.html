How to launch

Folded away so the ads stay up top. Open what you need.

Go-live checklist
{{CHECKLIST}}
Upload an ad in Meta Ads Manager
  1. Download the ad's three files: 1:1 (Feed), 9:16 (Stories + Reels) and 1.91:1 (right column, in-stream, search).
  2. Go to the service's ad set (Menopause, Longevity, or the IV iron campaign). Start with the ads marked Test now.
  3. Create ad and name it with the ID on its card (e.g. MV3-T, M3). Identity: the Optimal Facebook Page and @beoptimal.ca.
  4. Media: upload the 1:1 file, then customize placements: Stories and Reels get the 9:16 file; right column, search and in-stream get the 1.91:1 file.
  5. Text: paste the primary text, headline and description with the Copy buttons. Use the service's website URL, URL parameters and CTA from the box at the top of its section.
  6. Videos: upload the matching thumbnail, and turn off auto captions (ours are burned in), Advantage+ music and creative enhancements. Publish, then leave it alone for 7 days.
What to test first (and when to swap)
{{PLAN}}
  • One ad set per service with its Test now ads, broad audience, Advantage+ placements. Hands off for 7 days, and duplicate instead of editing.
  • Judge on booked intro calls per ad (Ad Lab matches bookings through the URL parameters), not on Meta's "results".
  • Day 7: pause any ad that spent $40+ with no bookings and a CTR under half the ad set's. Day 14: swap the bottom two for Next up ads.
  • Fatigue: when frequency passes about 3 or CTR drops about 30%, swap in the ad's Twin.
  • Chantelle vs Cheryl: run MV1-T against MV3-T as a Meta A/B test with equal budgets. They're the same length, end card and page, so the only difference is who's on camera.
